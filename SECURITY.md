# Security Policy

Lull talks to a BedJet over Bluetooth and has no servers or accounts. Security issues most likely
involve the Bluetooth link: for example, another device taking control of a BedJet through Lull, or
the phone-to-phone hand-over being abused.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/rkanjani/lull/security/advisories/new)).

Include what you found, how to reproduce it, and the impact you expect. You'll get a reply within a
week, and credit in the fix if you'd like it.
