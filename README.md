# Screenshots for pull requests

The images the descriptions of my pull requests to rkanjani/lull show, kept on this branch so the
pull requests don't add them to the app's repository. Each folder under `screenshots/` is one feature:

- `live-activity`: Live Activity and Android Live Update (rkanjani/lull#24, was #16)
- `standby-widgets`: Both Sides and Quick Remote widgets, and Tonight in StandBy (#25, was #17)
- `watch-apps`: Apple Watch and Wear OS apps (#18). `frame.swift` draws the shots into a watch.
- `wake-time`: wake times, and the Remote turning off at a time (#19)
- `firmware-update`: firmware updates and Wi-Fi for a BedJet 3 (#26, was #20)
- `shortcuts`: Shortcuts actions and automation apps (#22)

Link to an image as `https://github.com/guineapigarmy/lull/blob/images/screenshots/<feature>/<file>?raw=true`.
